# دفتر الحسابات

كشف حساب الموردين والعملاء — حاصلات زراعية.
تطبيق ويب يشتغل **بدون إنترنت**، والبيانات محفوظة على الجهاز نفسه.

**افتحه من هنا:** https://tedawy.github.io/daftar/

## التثبيت على الموبايل

- **iPhone** — افتح اللينك في **Safari** → زرار المشاركة → *Add to Home Screen*.
  (لازم Safari، مش Chrome — دي الطريقة الوحيدة على iOS.)
- **Android** — افتح اللينك في Chrome → *Add to home screen* أو زرار التثبيت.
- **كمبيوتر** — Chrome أو Edge → أيقونة التثبيت في شريط العنوان.

## البيانات

كل جهاز بيبدأ بدفتر فاضي، والبيانات بتفضل على الجهاز — مفيش سيرفر ومفيش حساب.
للنقل بين الأجهزة: **تصدير نسخة** من الجهاز الأول، و**استيراد نسخة** على التاني.
